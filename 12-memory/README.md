# 12-memory — the compounding loop

The OS gets smarter only if sessions write back what they learned.

| File | What goes in |
|---|---|
| `strategy.md` | Where you're going and why — change deliberately, never casually |
| `decisions_log.md` | Significant decisions, with the reasoning |
| `lessons_learned.md` | What broke, what you learned, what changed |
| `ideas_vault.md` | Raw ideas — capture now, evaluate later |

Format, always: `## [YYYY-MM-DD] — Title`
Append via: `python 07-scripts/core/memory_update.py <file> <title> <content>`
